# 02 Empathize — provider conversation (Fri evening, venue Q&A)

We learned the jury-facing priority is a pipeline with clear documentation and
reasoning for training and testing humanoid robots, scoped for now to stair
climbing, but judged with the workshop context in mind: obstacles, slippery
floors, stair turns. We think documentation and reasoning outrank raw task
performance, because SKF must trust and reproduce whatever we show. We still
need to verify what "testable in real life" concretely requires (is a G1
available to us? which success measures convince a process specialist?).

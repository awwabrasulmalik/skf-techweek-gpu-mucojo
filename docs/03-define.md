# 03 Define — shared direction

How might we help SKF achieve reliable stair-capable humanoid locomotion when workshop floors add obstacles, low friction and turns, and every training step must be documented, reproducible and explainable?

Scope decision (Route A, depth): one task — vision-based stair climbing (step-length
adjustment kept as fallback) — full pipeline ending at simulation, with docs,
video, and a proposed SKF use-case pipeline. Workshop context (obstacles,
slippery floors, stair turns) is carried as named domain-randomization axes so
the depth result reads as a credible stepping stone, not a lab toy.
